Privacy Policy: Real Number Studio

Last updated: 1 November 2026

Real Number Studio is a private tool used only by the owner of The Real Number to publish its own videos to its own YouTube channel and Instagram account.

  • It uses Google's YouTube Data API only to upload videos to the owner's channel. It does not read, collect or store data about any other user.
  • Access tokens are stored encrypted in the owner's GitHub repository secrets and are never shared.
  • No personal data is sold, shared or used for advertising.

Real Number Studio's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
