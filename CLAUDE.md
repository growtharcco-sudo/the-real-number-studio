# The Real Number Studio

This repo produces and posts one Reel a day for The Real Number (Instagram @the_real.number, YouTube @Thereal.number).
For the daily run, follow `ROUTINE.md` step by step. Never post directly: queue it, and GitHub Actions posts at `post_at`.
Hard rules: every number verified from a source fetched the same day and run in Python; no investment advice;
no em dashes; Instagram caption ends with exactly 5 hashtags including #therealnumber; voice is Kokoro am_michael.
If James replies "skip", create `queue/<id>/SKIP`, commit and push.
